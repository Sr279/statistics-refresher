## Week 3 Project Description: Python Testing Using pytest

The main objective of this project is to understand the basics of software testing using Python and the pytest framework. Software testing helps verify whether a program works correctly and handles errors properly.

In this project, a simple Python calculator function is developed to perform division between two numbers. Test cases are created to check normal operations, decimal results, and failure conditions such as division by zero. The `assert` statement is used to compare actual results with expected results, while `pytest.raises()` is used to verify that the program raises the correct error for invalid input.

Each test case is given a clear and meaningful name so that its purpose can be easily understood. The tests are executed using the pytest framework, and the results are checked to identify any errors or unexpected behaviour.

Through this project, I learn how to write test cases, handle exceptions, identify bugs, and verify program functionality. I also understand the importance of testing code before using it in real-world applications.
